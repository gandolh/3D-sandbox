# Assets

All assets are **CC0**. Raw downloads are committed; anything large is gitignored
(`assets-src/**/*_4k.*`), so the 1k and 2k variants live in git and 4k does not.

## Sources, with real inventory

| Source | Licence | Inventory (checked 2026-09-11) | Use |
|---|---|---|---|
| [Poly Haven](https://polyhaven.com) | CC0 site-wide | 995 HDRIs · 859 textures · 521 models, **native glTF at 1k/2k/4k** | The anchor — the only source serving glTF directly |
| [ambientCG](https://ambientcg.com) | CC0 site-wide | ~2 890 assets, ~2 009 PBR materials, ~425 HDRIs | Material depth Poly Haven lacks |
| [cgbookcase](https://cgbookcase.com) | CC0 | Small, hand-authored | Architectural surfaces |
| [Sketchfab](https://sketchfab.com) / [BlendSwap](https://blendswap.com) | **per-asset** | Large, mixed CC0 / CC-BY | Gap-filling only — check every licence |

## Why solar time works so well here

Of Poly Haven's 995 HDRIs: **703 outdoor, 820 natural-light, 331
morning-afternoon, 223 sunrise-sunset, 206 midday, 299 pure skies.** That is dense
enough to *match an HDRI to a time of day* rather than tint a procedural sky, which
is what makes [solar time](./glossary.md) a real lighting change instead of a
colour shift.

## Getting the files

`npm run assets` regenerates, from the scenes themselves:

- `assets-src/DOWNLOADS.md` — the table of what is referenced, by what
- `assets-src/download.sh` — a runnable script that fetches it all into place
- `assets/verified.json` — the committed offline guard

It exits non-zero on a slug that does not resolve, so adding an asset to a scene
and running it is the verification step. Resolution is **2k**: 4k and 8k are
gitignored, and 2k is what a 1920 × 1080 render can resolve.

## The weight of photoreal vegetation

Measured 2026-09-11 against the 2k glTF, which is the resolution this project
commits:

| Asset | Mesh (`.bin`) | Textures | Total |
|---|---|---|---|
| `pine_tree_01` | **904.9 MB** | 31.7 MB | 936.7 MB |
| `fir_tree_01` | 456.3 MB | 30.3 MB | 486.6 MB |
| `tree_small_02` | 90.7 MB | 19.3 MB | 110.0 MB |
| `ArmChair_01` | 0.1 MB | 2.5 MB | 2.7 MB |
| everything else | — | — | under 11 MB each |

Three trees are **1,533 MB**; the other seventeen assets together are 88 MB.

This contradicts the sizing behind the two-tier decision, which says "a photoreal
tree is 50–200k triangles". It is out by roughly two orders of magnitude — 905 MB
of buffer is tens of millions of vertices, every needle modelled. The *decision*
is more right than it knew; the *number* in it was wrong.

**Instancing does not rescue this.** A 905 MB mesh is 905 MB whether it appears
once or 284 times: it still has to reach the GPU, and a BVH still has to be built
over it. Tiering saves draw calls and authoring effort, not bytes.

So `npm run assets` splits its output. `download.sh` fetches the 88 MB that is
usable as-is; `download-heavy.sh` fetches the trees separately and is explicitly
a *decimation source*, not something to commit. Turning those into a scatter LOD
is unbuilt — see [open-questions.md](open-questions.md).

## The vegetation gap — a live constraint, not a nice-to-have

**Poly Haven has 20 tree models, and most are wrong for a temperate European
site.** The catalogue skews arid and southern-African: `quiver_tree_01`,
`quiver_tree_02`, `searsia_burchellii`, `searsia_lucida`, `othonna_cerarioides`,
`jacaranda_tree`, `island_tree_01..03`. What is usable for a Romanian plot is
roughly three models — `pine_tree_01`, `fir_tree_01`, `tree_small_02` — plus
saplings (`fir_sapling`, `pine_sapling_medium`, `pine_sapling_small`) and stumps.

Two consequences:

1. **A forest is 3–5 species, varied by scale and rotation**, not 20. This is
   already how `ScatterField` works (`scaleRange`, `seed`), and it is now the
   reason, not a convenience.
2. **Invented slugs are a real failure mode, and hand-verification does not
   stop it.** Three tree ids in `villa-carpathia`'s first draft did not exist
   (`birch_tree_02`, `oak_tree_01`). This note was then written — and *eight more*
   were invented in Greenhollow one change later (`apple_tree_01`, `rose_bush_01`,
   `Fountain_01` and five others). A written rule nobody can run is a note.

   It is now enforced, in two layers, and both are armed at all times:

   - **`assets/verified.json`** — committed, generated by `npm run assets`,
     listing slugs confirmed to exist at their source. Checked **offline** by
     `npm run scenes`, so a fresh clone and CI both catch an invented slug with
     nothing downloaded.
   - **`assets-src/`** — what is actually downloaded, scanned by
     `assets/manifest.ts`. Its ids are added to the verified ones, so a local
     asset that predates a regeneration still resolves.

   There is deliberately **no state in which the rule is off**. An arming
   condition that can evaluate to "disabled" is how this failed the first time.

   The rule asks *does this slug exist*, not *is it on this machine*. Presence
   was briefly the stricter standard, and it was incoherent: not downloading the
   heavy assets is the designed state, so every build failed. A missing **file**
   is the generator's problem and it falls back to a proxy; a missing **asset**
   is the author's, and that is what is caught here.

Furniture is thin for the same reason: 85 models, skewed vintage and industrial
(a gothic armchair, a barber's chair, barrels). Materials and lighting are solved;
**models are not**.

### What Greenhollow substitutes, and why

Verified against the live API on 2026-09-11. Poly Haven has **no fruit trees, no
roses, no fountain and no vegetable bed**.

| Wanted | Used | Reasoning |
|---|---|---|
| apple / pear / plum | `tree_small_02` | There are no fruit trees. Row spacing is what makes an orchard read as one, not species. |
| roses | `shrub_01`–`shrub_04` | Temperate, from `verdant_trail`. Reads as a clipped flowering border at the distance the alley is seen from. |
| vegetable beds | `planter_box_01`–`03` | Closer to a kitchen garden than anything else in the catalogue. |
| garden bench | `painted_wooden_bench` | Exists, and is the right thing. |
| fountain | *dropped* | None exists. The pond reads better alone than with a proxy box in the middle of it. |
